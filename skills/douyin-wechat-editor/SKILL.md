# 抖音热点 → 公众号本地文章包

这是四账号的个人编辑工作流，不是微信平台的官方审核标准。默认终点是本地交付，不是上传、发表或声明原创。Skill由Codex协调浏览器、检索、ImageGen和本地工具，不是无人值守爬虫。

## 入口和边界

- 先确定唯一账号：`digital` 手机数码、`basketball` 篮球、`dream` 梦幻西游、`entertainment` 娱乐。用户未指定且上下文无法确定时再问。
- 工作区有 `AGENTS.md`、`README_四账号统一编辑规范补充.md` 和相应账号清单时先读；用户当前要求及工作区新规则优先。不要用另一账号的后台数据代当前账号判断。
- 自主找素材先读 [research.md](references/research.md)；指定视频直接做来源登记；已有 `article-job.json` 先运行 `status`，从未完成阶段续做，不重建任务或重复生成封面。
- 每篇都读 [editorial.md](references/editorial.md)、[visuals.md](references/visuals.md) 和 [pipeline.md](references/pipeline.md)。正式封面前读取可用的 `$imagegen` 技能，使用内置ImageGen。转写遵循当前环境的转写工具说明。
- 只下载允许使用且可见页面提供的素材；可浏览不等于转载许可。权限不明可整理研究底稿，不能把“本地通过”说成版权授权或可声明原创。

## 工作顺序

1. **预检**：检查浏览器控制、ImageGen、Python/Pillow、ffmpeg/ffprobe、Node/Playwright及中文字体。用 `scripts/source_tools.py doctor` 检查本地依赖，不要做到最后才发现封面或预览不可用。
2. **自主选题**：新建4个研究标签，分别搜索、原视频、官方资料、交叉核验；播放前静音并核验，导航后再检查。验证码由用户完成。保留3至5个候选和淘汰理由；上传日期不等于事件日期。
3. **独立任务**：`article_pipeline.py init` 创建目录；登记来源网页、作者、发布时间、事件日期、访问时间、复用权限状态和候选记录。视频放任务 `source/`，运行 `source_tools.py bind` 绑定真实视频哈希与时长。
4. **证据先行**：本地转写，按关键台词/属性/结果/动作抽帧，不只等间距截屏。先看原帧再写台账；区分“主播说”“画面显示”“编辑推断”。视频、主张、账号、任务目录必须一致。
5. **信息增量**：先补一手来源和有效比较再决定独立成文。达不到编辑门槛保持 `hold` 或 `merge`，不以加图、换词或凑500字替代增量。
6. **标题正文**：两套标题各4种模型候选，选两条不同问句骨架的最终标题；短标题≤20字符。正文约500中文字符，开头回答标题，完成去AI腔改稿和同账号近期查重。
7. **视觉**：约3个正文配图单元，优先1张视频大图+2组不同主张的4至6帧单列大拼图，两组间有正文解释。材料不足登记例外，不凑相似帧。ImageGen基于真实素材制作3:4和2.35:1两张原生中文文字封面；梦幻不造人物、道具或奇幻背景。
8. **交付检查**：`render → preview → 目视质检 → validate`。修改正文、图、封面或台账后重新渲染/预览。检查375px下每帧文字、双封面缩略图与横版中央方裁。将实际检查写入 `qa.review` 和审核记录文件，不能提前填通过。
9. **集中交付**：两条最终标题、实际正文中文字符数、验证结果，及同一处的4个真实链接：HTML文章、手机预览、3:4竖封面、2.35:1横封面。明确“本地质检完成，未上传/发表”。缺项或未过不能称完整发布包。

## 不打扰与节奏

- 内置浏览器默认静音；无法确认时暂停/离开播放页，不改系统全局音量。只有用户当前明确要求声音才解除。
- 4个研究页不等于成品展示许可；不自动打开HTML、长图或资源管理器。无头预览与 `view_image` 用于QA，最终只给链接。
- 记录来源、阶段、失败原因、下一步和耗时。独立工具工作可并行，但不另建用户任务或子代理，除非获得相应授权。
- 工具超时先检查已有文件/页面/生成结果，避免重复操作；同类失败且无新证据时说明阻塞，不无限重试。
- 不重复全量转写、重复全量搜索，也不为提速省略核验。一次制作耗时不能推广到四个账号。

## 工具职责

`article_pipeline.py` 管理任务、渲染、预览和验证；`source_tools.py` 做依赖诊断、来源绑定、原始抽帧；`build_evidence_collage.py` 确定性拼图；`audit_title_hooks.py` 做标题启发式检查。脚本不登录抖音、不调用隐藏接口、不自动调用收费服务、不发表文章。

脚本只校验文件、结构、引用和审查记录的一致性。事实真假、信息增量、中文出字和人物漂移仍需阅读与目视检查；不能用布尔字段替代审核，也不保证平台推荐或“低创作度”审核结果。
