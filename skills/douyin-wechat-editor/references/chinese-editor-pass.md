# 一次中文总编改稿：具体、自然、有证据

这是编辑方法，不是模型训练、AI检测规避或推荐保证。不要串联多个humanizer反复洗稿；模型、账号语气与调度由当前用户决定。

1. 锁定事实：人名/型号/技能、数字、日期、引语、否定、因果、比较条件和“工程机、挂价、主播推测”等限定。
2. 先修读者主线、推理跨度和信息取舍，再修生硬句。去掉“本篇不能做榜单、六条事实已核验”等内部工作说明；不把审稿栏目搬进正文。
3. 开头用本篇真实动作、画面、原话或具体操作进入，允许一两句情境，在首段3–5行内自然答题。不要每篇都“先说结论：不能……”；也不故意吊胃口。
4. 结尾停在本篇最后一个有用结果、原话、画面或判断。中段已说明的答案和边界不复述；末段只剩重复就删除，不强补互动问句、金句、劝等或检查清单。必要条件就近放在相关主张旁，不能删掉。
5. 对比最近5篇同账号可读成稿首末两句和同批其他账号；不足5篇按实有篇数。检查是否只换人名数字就能互换。改变切入事实和停笔位置，不按固定句型库轮流套用。无历史如实记录。
6. 保留本来就自然的句子。不要用故意错字、固定口头禅、“兄弟们”、假亲历、假共识或虚构情绪装人味。单个转折词不是禁词，重点是它是否提供信息。
7. 改后对照证据复核数字、对象、范围、否定、时序、归属和标题答案，再count完整正文。必要的信息增量必须真实进入正文支撑判断。

在analysis/voice-review.md记录实际参考路径、发现的重复模式、改前/改后、理由、事实回查和仍需补证处；未发现问题说明依据，不为留痕硬改。它是内部记录，不进入公开正文。模板填满不等于审稿完成。

账号语气：数码讲具体使用后果与有条件选择；篮球讲动作、对抗和完整事件；梦幻讲真实属性、机制、成本；娱乐讲公开作品、原话和回应，不猜私生活。
