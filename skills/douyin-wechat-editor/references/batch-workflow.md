# 多账号批次与续做

仅在用户请求多个账号或已经配置定时任务时使用，不自行创建调度、改模型、开新聊天或子代理。时间与模型由用户自己的设置决定；此分享包不带原作者自动任务。

- 用日期+时段+账号作为幂等身份，读取历史及在制记录；同一未完成任务在原目录续做，不重转写、不重做已有合格封面。另一执行者拥有该轮次时只报告状态，不改run、报告或浏览器。
- 建立/恢复本轮记录后，慢工具前先保存本轮研究报告。记录真实候选、来源、日期/互动观察时间、查重、可核事实、缺项与下一步。没有读到网页就写执行故障，不假装研究过热点。
- 全账号先完成候选可行性初筛，再精修证据最完整的一篇；本地转写或生图等待时推进其他独立工作，不同时控制同一标签。公共依赖/故障仅检查一次。
- 候选连续约5分钟无新增证据就换备用；无当天合适素材按research.md扩窗。不能因计时结束放弃仍可完成的工作，也不能为交满数量虚构热点、增量或PASS。
- 每阶段与约10分钟更新报告、实际完成X/N及卡点；报告不计为文章。停止前保存进度，未完成明确hold/阻塞原因。全部文件仍属于各自账号/任务，不混用。
- 新策略每篇只核对三项：HTML、竖封面、横封面及delivery-manifest哈希。不因没有手机预览报缺件；历史旧策略保留四项。不删除历史预览。
- 最后给报告链接与“文章部分完成X/N”，已完成稿提供三项存在性检查后的绝对路径。未上传/未发表。真实无人值守成功才能证明调度运行正常；本地测试不等于调度器或登录故障已修复。
